# 神门星 × 干支五行生克

八神、八门、九星与干支做生克。事项按吉神凶神改断语；天气收成 12 个 0/1 送进回归。

实现：`src/engine/wuxing-symbol.ts`。重训：`npm run train:weather`。

## 64 维

1–31 神门星格局季节；32–52 四柱地盘；53–64 神/门/星 × 吉被生、吉被克、凶被生、凶被克。

气候带 12 站各自 64 维。区县 3143 套仍是 31 维本体，推理叠 `sharedTail`（四柱 21 + 生克 12）。
