# 神门星 × 干支五行生克

奇门盘上的八神、八门、九星（古法常说八星，本库按九星，天英单独作中性）各有五行。这一层把它们和**年月日时干支、地盘干支**做生克，再按吉神凶神改断语和分值。

实现：`src/engine/wuxing-symbol.ts`。事项、运势走 `ganzhiFlags()` → `symbolWuxingFlags()`。天气向量在四柱 21 维后再接 12 维 0/1。

## 五行归属

| 类 | 五行 |
|---|---|
| 八神 | 值符土、腾蛇火、太阴金、六合木、白虎金、玄武水、九地土、九天金 |
| 八门 | 休水、生土、伤木、杜木、景火、死土、惊金、开金 |
| 九星 | 蓬水、芮土、冲木、辅木、禽土、心金、柱金、任土、英火 |

## 吉凶

| | 吉 | 凶 | 中 |
|---|---|---|---|
| 神 | 值符、九天、九地、太阴、六合 | 腾蛇、白虎、玄武 | — |
| 门 | 开、休、生 | 伤、杜、死、惊 | 景门 |
| 星 | 辅、心、任、禽、冲 | 蓬、芮、柱 | 天英 |

## 断法

- 被生则旺。
- 吉神被生 → 吉；吉神被克 → 小吉，克重可滑小凶。
- 凶神被生 → 明灾、小凶。
- 凶神被克 → 灾更隐蔽、更凶。
